# Artifacts

Import wandb: log_dataset(wandb,...) or log_model(wandb,...). artifact_name covers dataset/model/predictions/eval-results/code: lowercase [a-z0-9._-], 128 max, digest fallback. Builders use aliases for dates/status/vN; explicit W&B-valid names only warn. Cards: Produced by, redacted Command, Inputs, Contents, Intended use, Caveats (units/transforms, ids/genome, splits/filters). Metadata: file stats, counts/splits/features, arch/family/step/metrics, eval_set/rows/columns/model. Over 2 GiB: references; reference=True/False overrides. URIs use add_reference; file:// needs its mount, object URIs need credentials. checksum=False: immutable storage. Caveat: shared-storage:/path/to/data requires its mount. use_input(run,"t/p/data:v3") resolves/warns on aliases and atomically saves id-bound output_dir/wandb_inputs.json on resume. No output_dir: run-object lifetime. Disk reads create no edge; include parent checkpoints. latest is newest; models get step-N/caller-selected best. <!-- declaration: logging.conventions -->
