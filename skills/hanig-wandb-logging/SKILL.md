# hanig-wandb-logging

## Host capability boundary

Use the active host's real file and shell capabilities and authorized W&B
access. This skill installs no package, credentials, connector or service.
The caller installs and imports W&B in its own project and passes it to wbkit.
Measured with wandb 0.31.0; other versions are best effort. Missing access is
reported as an incomplete logging check.

Set `HANIG_WANDB_LOGGING_DIR` to the directory holding this loaded SKILL.md.
Copy [wbkit](scripts/wbkit.py) from there into the training project. Inputs
and outputs stay relative to the project directory.

The training logging requirement lives in hanig-project and hanig-swarm;
this skill explains how to apply it.

## Workflow

1. Read the entry point, config, ranks and existing logging.
2. Show entity/project, group, name, notes, config, axis and summaries.
3. Vendor wbkit, then wire it into project code. See [naming](references/naming.md)
   and [frameworks](references/frameworks.md).
4. Smoke-test offline; inspect lint, config, axes and resume; report observations.

```python
import wandb  # installed by the training project
import wbkit

run = wbkit.start_run(wandb,
    project="sample-pretrain", family="sample", job_type="train",
    model="sample", data="cells",
    hypothesis="The new recipe lowers held-out loss.",
    expect="val/loss < 0.5",  # quote the predeclared predicate
    config={"arch": arch_cfg, "train": train_cfg, "data": data_cfg},
    base_config=base_cfg, group="20261110-recipe-ablation",
    summaries={"val/loss": "min", "val/score": "max"},
    output_dir=out_dir)
wbkit.log_step(run, step, {"train/loss": loss, "opt/lr": lr})
wbkit.finish(run, outcome=contract_result, verdict=contract_verdict)
```

Reuse one output_dir per logical run across requeues. It stores sanitized
launch config/provenance, id and resume count. New experiments use new output
directories. Restore training checkpoints separately and log optimizer steps.
Direct SDK writes and unlabeled free-text credentials remain caller-owned.
`finish` appends Outcome (verdict), prints lint and closes the run.
